# Proposed protocol: fictional teaching exercise

Eight fictional participants each complete two four-minute proofreading blocks.
Every passage contains 12 planted typographic errors. One block follows a
five-minute quiet break; the other follows five minutes of continuous reading.
The two block orders are balanced across the eight records.

The recorded outcomes are correctly detected planted errors and false flags.
The primary descriptive contrast is break minus continuous-reading detections
within each participant. Each detection count has denominator 12. False flags
are counts, not rates: the number of error-free opportunities is not supplied.

The passages differ. Their difficulty has not been validated. The plan does not
yet specify passage-to-condition counterbalancing, randomization, washout,
eligibility, recruitment or a justified sample size. The preceding reading task
and a break could have effects that carry into the next block.

Before using this as an actual study, its scientific owner would need to resolve
these design issues and applicable human-research requirements. The present
packet supplies neither approval nor a validated procedure.
