# 🛠️ Engineering Workbench

## Target and success criteria

The fictional display needs a visible power indicator that can be switched off. This example uses one resistor, one LED and one switch. No microcontroller, software or optional research modality is needed.

The documentation task succeeds when a reader can trace every connection, find the source of a component limit, distinguish an upper-bound calculation from a measurement, and identify the checks still needed on physical hardware.

## Constraints

- Use the specified 3.0 V DC source limit and series resistor. Do not substitute a higher-voltage source.
- The required tutorial activity is the paper review. Physical assembly is optional and requires the equipment and skills in the test plan.
- No mains wiring, battery charging, medical use or connection to a person is part of this project.

## Open questions

- Does the actual breadboard match the assumed connections between holes?
- Are the actual LED identity, resistor value, source setting and polarity correct?
- Is the LED sufficiently visible at the resulting low current?

None of these physical questions has been answered by this fixture.
