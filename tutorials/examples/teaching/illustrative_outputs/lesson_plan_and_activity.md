# Illustrative Week 2 lesson and activity

Authored illustrative output for the fictional INX 104 course. The plan uses the [syllabus](../inputs/instructor_syllabus.md), [source pack](../inputs/week_02_sources.md) and [activity](../inputs/activity_rubric_and_student_work.md#student-activity). It prepares the March 11 meeting from 09:00 to 09:50 UTC.

## Learning focus

Learners should be able to preserve the incomplete-label and fragile-rule priorities, then verify a selected tray against its register code. These actions correspond to rubric criteria C and D. Starting conditions and sequencing remain required under criteria A and B.

## Fifty-minute sequence

| Minutes | Teaching and student work |
| --- | --- |
| 0 to 5 | Show a large fragile parcel. Ask learners to choose a tray privately before discussing their reasoning. |
| 5 to 12 | Explain the four components of a complete procedure using T1. Trace the routing order in T2. |
| 12 to 17 | Work through P0, the large non-fragile case from T4. Show the tray, code and final comparison. |
| 17 to 22 | Use learning check 1 below. Allow an answer before giving the explanation. |
| 22 to 34 | Pairs draft a procedure and trace P1, P2 and P3 using the student activity. |
| 34 to 40 | Use learning check 2. Compare an undefined or guessed destination with the source's Hold rule. |
| 40 to 47 | Learners revise their procedure and add a tray/code check. Partners identify the deciding step for each card. |
| 47 to 50 | Exit response. Name one revision and the case that made it necessary. Restate the activity's Friday deadline. |

## An explanation the instructor could say

“Think of the rules as questions in a fixed order. First, can we read both fields and do their values fit the exercise? If we cannot, Hold is already the answer. If the label is complete, ask about fragile next. A large fragile parcel still goes to Blue because that question comes before the remaining size rule. Once the parcel reaches a tray, the job has one more step. Check that the written code names the tray where the parcel actually sits.”

## Learning check 1

One question display is sufficient.

**A parcel has a complete label with size large and fragile yes. Which tray should the procedure select?**

- A. Red
- B. Blue
- C. Hold
- D. Either Red or Blue

Presenter explanation after students respond. **B, Blue.** T2 rule 2 is the first matching rule. Red applies to a large parcel only after the fragile condition has been ruled out. Choosing Red suggests that the procedure checked size too early.

## Learning check 2

**A parcel's size field is missing and fragile says no. What should happen?**

- A. Infer the size and select Red or Blue
- B. Skip the parcel without recording it
- C. Place it in Hold, record H, verify the match and mark complete
- D. Place it in Blue because fragile says no

Presenter explanation after students respond. **C.** The label is incomplete under T1, so T2 rule 1 applies before fragile or size. T3 still requires a record and completion check.

## Student handout content

Use the [Student activity section](../inputs/activity_rubric_and_student_work.md#student-activity), its three parcel cards and the published rubric. Have pairs exchange procedures and trace each card without filling in an unstated rule. Then ask them to revise any step that produced a wrong or undefined result.

The instructor uses the separately labelled key to explain feedback. Planning times and this key remain preparation material when assembling a student-facing handout.

## Customization

Change the fictional objects, field names or routing rules together with the cases and answer key. Adjust the 50-minute allocation to the actual class period while retaining response and feedback time. Preserve any instructor-approved source and grading boundaries in the replacement course.
