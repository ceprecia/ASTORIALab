# Week 2 activity, rubric and fictional student work

Fictional instructor preparation input, version 1.0. Every parcel and submission below was invented for this tutorial. The student activity, instructor key and sample submission are labelled separately so the instructor can select the appropriate material.

## Student activity

Write a numbered procedure for the Parcel Table using the [approved source pack](week_02_sources.md). Include the starting checks, ordered routing rules, one register code and an observable completion check. You may refer to the rule numbers, but the procedure itself must tell a reader what to do.

Trace your procedure on all three cards. Record the selected tray and code and identify the step that determined each result.

| Card | Size field | Fragile field |
| --- | --- | --- |
| P1 | small, legible | no, legible |
| P2 | large, legible | yes, legible |
| P3 | missing | no, legible |

Submit the procedure and three traces by Friday March 14, 2031, at 17:00 UTC. This activity is worth eight points. The criteria below are available to learners.

## Rubric

Each criterion receives 0, 1 or 2 points, for a maximum of eight. Score the written evidence against each anchor independently.

| Criterion | 2 points | 1 point | 0 points |
| --- | --- | --- | --- |
| A. Starting conditions | Identifies the parcel, labelled trays and register, and checks both fields for permitted, legible values | Names an input or needed material but leaves one or more starting checks incomplete | Gives no starting condition or input check |
| B. Action sequence | For a complete label, gives a followable sequence from reading the parcel to selecting a tray and recording the choice | For a complete label, gives a usable sequence with an ambiguous or missing transition | Even for a complete label, the sequence cannot be followed far enough to select and record a destination |
| C. Rule priority | Handles incomplete labels first, then fragile parcels before the remaining size rule | Correctly handles one of the incomplete-label or fragile priority cases, with the other missing or wrong | Both priority cases are missing or wrong |
| D. Completion check | Records one code, verifies it against the tray, and explicitly marks complete or stops | Records a code but omits verification or an explicit completion condition | Provides neither a record nor a completion check |

## Fictional submission

Sample learner K submitted this invented draft.

> 1. Read the size label.
> 2. If the parcel is large, put it in Red.
> 3. Otherwise put it in Blue.
> 4. Write R or B to match the tray you used.

The sample includes no case traces. For this exercise, score the four written-procedure criteria above and report the missing traces as an additional submission-completeness finding. The rubric assigns no separate trace points, so do not invent an extra numerical penalty.

## Feedback task

Propose the four criterion scores with quoted evidence. Explain the consequence of one missing rule using a supplied parcel. Give two priority revisions and a short corrected procedure for comparison. Keep the result as a feedback draft for the fictional instructor's review.
