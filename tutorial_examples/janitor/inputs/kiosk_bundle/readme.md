# Fictional kiosk content package

This is a small dependency-preservation fixture, not runnable kiosk software.
Its [manifest](manifest.json) names the [label table](labels.csv) and
[display note](assets/display_note.txt) by relative path. Keep those filenames
and the whole folder together.

The exhibit map outside this package links to this readme. Moving the package
requires repairing that incoming link, not renaming its internal files.
