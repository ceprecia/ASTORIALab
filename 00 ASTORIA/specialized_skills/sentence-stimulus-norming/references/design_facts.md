# Design facts that control the review (sentence-stimulus-norming)

Read this reference when the skill or the user asks for it.

## Design facts that control the review

### Candidate creation and controls

- Create condition variants with nonmanipulated content held constant where
  scientifically possible. Record every residual lexical, morphological,
  syntactic, semantic, discourse, length, punctuation, prosodic, and
  presentation difference.
- An overcomplete pool is provisional. Each item remains linked across
  conditions and retains source and version provenance.
- Corpus frequency, lexical databases, embeddings, language models, and
  published norms can inform a candidate. They do not substitute for a human
  construct measure by default. A missing corpus value is missing, never zero.
- Verify each database or corpus language, variety, release, coverage,
  preprocessing, license, redistribution rule, and access date before use.

### Cloze and rating design

- Predefine cloze context truncation, single versus multiple completion,
  tokenization, spelling, morphology, capitalization, diacritics, clitics,
  multiword answers, response collapsing, adjudication, invalid responses, and
  denominator.
- Preserve the raw completion distribution. Target cloze alone can hide
  different alternative distributions and entropy.
- For ambiguity, preserve meaning-dominance and sentence-interpretation responses,
  including `other` or `unclear`, with blinded coding, adjudication, and coder reliability.
- Zero target cloze does not mean that a continuation is anomalous,
  implausible, unacceptable, or ungrammatical.
- Measure full-event plausibility compositionally in context when relevant;
  target frequency or pairwise association is not a substitute.
- Instructions, anchors, scale format, context, order, fillers, and prior
  exposure can change responses. There is no universal seven-point scale.
- Normers should match the target language or variety, age, proficiency,
  culture, modality, and intended population where the inference requires it.
  Use independent human normers from the main study when feasible.

### Selection and revision

- Rater sampling and item sampling jointly determine uncertainty. A large
  rater count does not repair a weak or unrepresentative item pool.
- Match reliability to the intended aggregate, item, coder, split-half, or
  test-retest inference; report distributions, missingness, and uncertainty.
- One rater sees at most one version of a base item unless the user approves otherwise.
  Retain approved list-rotation ID, order, seed, and constraint evidence.
- A nonsignificant difference does not establish matching or equivalence.
  Equivalence requires a separately approved substantive bound and method.
- Post-norm edits can invalidate the prior norm state. Version every sentence,
  re-norm changed material, or mark it unverified.
- Norming supports control and selection. It does not validate a hypothesis,
  prove a grammar, establish a causal mechanism, or convert an exploratory
  item revision into a confirmatory test.
