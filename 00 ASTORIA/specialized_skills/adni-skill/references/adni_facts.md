# ADNI facts that control the review (adni-skill)

Read this reference when the skill or the user asks for it.

## ADNI facts that control the review

Use these as dated orientation and recheck them at invocation:

- ADNI began in 2004 and continues across ADNI1, ADNI-GO, ADNI2, ADNI3, and
  ADNI4. Participant pools, cohorts, diagnoses, schedules, scanners, protocols,
  measures, and file families differ by phase.
- ADNI is a rolling LONI Image and Data Archive, not a fixed semantic release.
  Electronic data capture content is updated daily, while laboratory and
  analysis files arrive on their own schedules. Record the query date and
  exact downloaded file versions.
- ADNI4 enrollment goals are planned targets, not current released counts.
- Current data access requires a qualified institutional affiliation, Data Use
  Agreement acceptance, an application describing intended use, DPC approval,
  and annual account updates.
- The current DUA prohibits reidentification, direct participant contact,
  redistribution of participant-level raw or derived data, and use of AI tools
  that lack guarantees that ADNI inputs remain contained.
- Team members who use the data must be declared and bound by the agreement.
  Derived participant-level data intended for sharing must go through the
  approved ADNI or NIA-designated route.
- Manuscripts using ADNI data require the prescribed authorship,
  acknowledgement, and administrative DPC submission process.
- MRI acquisition and processing differ across phases. The current FAQ notes
  that ADNI3 and ADNI4 do not add the same MRI-core preprocessing used for
  earlier acquisitions because vendor processing changed.
- Diagnosis, visit codes, imaging dates, PET dates, biomarkers, and assessment
  files require explicit reconciliation. A label at one visit does not define
  another visit.
- The March 2026 ADNI Data Advisory removed all data associated with 78
  participant IDs beginning `381_S_` and advises that they not be used. The
  live advisory and any replacement or deletion notices must be checked before
  specification and again before publication.
- ADNI genomics and related omics may be governed through NIAGADS, NACC, or
  another repository with separate access decisions.

Do not assume every phase, participant, visit, diagnosis, modality, biomarker,
or processed output is mutually linkable or complete.
