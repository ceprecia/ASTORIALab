## Stale-pattern families

Search active instructions (`00 ASTORIA/skills/`, `00 ASTORIA/systems/`, `00 ASTORIA/Skill Map.md`, `me.md`, `AGENTS.md`) for these. Exclude `02 📅 Calendar/capture-logs/`, `00 ASTORIA/agent_notes/`, `.obsidian/`, `.trash/`, and archived or frozen files unless the user asks.

- Capture routing: compare active instructions with the recipient's capture policy and current request. Keep each project original once in its owning MOC's Research Log, with an exact Calendar embed when the selected route includes Calendar. Preserve existing period groupings and supported index formats. Report duplicate full text and conflicting destinations.
- Startup configuration: check active instructions against the recipient's configured roots and documented dependencies. Keep project environment loading with the owning project. Treat passive writing references and historical records according to their own scope.
- Output destinations: verify the recipient's configured intake and delivery paths. Keep the human-owned Inbox outside AI output destinations. Report undeclared staging paths. Moving or deleting a delivered output does not establish a broken dependency.
- Finished projects: do not require active workspace registrations, recreate project scaffolding, or treat historical paths as live dependencies merely because a finished project remains available for reference.
- Skill shape: compare active skill folders and frontmatter with the current vocabulary and skill-builder schema. Each skill lives in its own folder with `SKILL.md`. Regenerate the Skill Map and catalogs from current metadata. Report mismatched file structures or fields.
- Agent instruction files: `CLAUDE.md`, `CLAUDE.local.md`, `codex.md`, `AGENTS.override.md`, `.claude/rules`, `GEMINI.md`. `AGENTS.md` is the only instruction file; `.claude/skills/` and `.agents/skills/` may exist only as symlink shims to `00 ASTORIA/skills/`.

Classify matches carefully: hits inside janitor pattern lists, report templates, or examples are audit instructions; hits that say a retired workflow is not active are boundary language; hits in protected capture logs are history; hits in active workflow instructions, descriptions, layout rules, or save behavior are drift. Do not edit historical hits in protected capture logs; report them separately.

## Related-skill contracts

- Engineering fit: fit-review, 3d-builder, wiring-design, engineering-test,
  assembly-builder, engineering-companion, engineering-coordinator and Engineering
  System agree on independent saved-model review, body/garment conformity where
  applicable, function/channel-to-component counts, complete finite working-cable
  paths, support/retention, occupied wiring and coupled motion/service coverage.
  CAD remains the author. Reproducible virtual experiments disclose configuration,
  collision/solver assumptions, deciding outputs and coverage; renders, kinematic
  checks, physics simulation and physical measurements are distinct evidence.

- Folder organization: folder-janitor owns requested filing outside the AI system root. The default Project or Area root has its MOC and AGENTS.md. Use a local files folder or a documented external workspace. Respect verified recipient placement and established operational layouts. Report missing entries without creating them. Resources collections retain their own organization. A new MOC link requires independent note-edit authority. Preserve surrounding prose, headings, decisions and historical provenance when repairing active paths. Propagate's move utility preserves write exclusions and handles reviewed literal-path repairs with the moves. A very large move or critical operational dependency needs one brief concrete plan/approval unless that scope was already approved; routine checks and coordinator handoffs do not repeat that checkpoint. Vault Builder owns separately scoped layout updates; coordinator detours preserve scope and return ownership. Examples do not prescribe the user's folder names. The capability is optional and its removal must not block unrelated sessions.

When a skill mentions or depends on another skill, compare the relevant contract between them. Flag disagreement as contract drift even when every file exists and every link resolves.
