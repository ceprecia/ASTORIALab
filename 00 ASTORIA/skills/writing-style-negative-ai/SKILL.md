# Writing Style: Negative, AI

Use this optional reference when the recipient requests an editorial review. Establish audience, genre, purpose and any supplied style specification first. The companion writing profile is another selectable reference; neither is an automatic preference stack.

## How a writing skill applies this profile

1. Identify the document's purpose and recipient-supplied style choices.
2. Check that claims, entities and logical relationships are understandable and supported.
3. Flag unresolved draft markers, ambiguous references and unnecessary repetition when they impair the selected purpose.
4. Offer revisions with their effect on meaning visible. Treat word choice, punctuation, headings, lists and rhythm as contextual decisions, not universal prohibitions.
5. Preserve protected surfaces and return factual gaps to the appropriate source owner.

The optional script reports unfinished draft markers and duplicate paragraphs. Its diagnostics are prompts for review, not evidence of AI authorship or scientific invalidity.

## Protected surfaces

Quotations, citations, data, statistics, code, transcript text, official titles, required terminology, and mandated wording are outside this profile. The checker skips recognized backtick and tilde fences at the top level or in simple list items, and top-level indented code. It also skips some inline code, quotations, citations and URLs. Check diagnostics against the source when the draft uses nested containers, raw HTML or other unsupported Markdown structures.
