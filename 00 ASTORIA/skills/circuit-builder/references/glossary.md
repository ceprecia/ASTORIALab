# Glossary

Define terms at first use in the walkthrough. Use this file as the fallback
list. Include a standalone build glossary when the reader requests one or the
applicable configured reporting form calls for one.

| Term | Meaning for a beginner |
| --- | --- |
| anode / cathode | The named terminals of a diode or LED. Conventional forward current goes from anode to cathode. Verify terminal identity and any markings in the documentation for the selected part and package. |
| bridge | an unwanted blob of solder joining two neighbouring pads |
| bus | a group of wires carrying a shared signal (I2C bus = SDA + SCL) |
| cold joint | a joint where the pad never got hot; dull, grainy, often not conducting |
| compliance | the largest load a current source can still drive at the asked current; beyond it the current drops |
| continuity | meter mode that beeps when the probes are joined by a conductor |
| designator | the name printed next to a part on a PCB (R1, C3, U2) |
| diode mode | Meter setting that applies a test current and reports voltage drop or a meter-specific indication. Use the verified plan and the selected component and meter documentation for lead orientation, expected readings and interpretation. |
| flux | a paste or liquid that cleans the metal as it heats so solder flows |
| footprint | the pattern of holes or pads a part occupies |
| GND / ground | A circuit's designated voltage reference. Use the verified plan to identify the reference and whether it connects to supply negative. |
| header | A connector with one or more rows of pins or sockets. Pitch is the spacing between adjacent contacts. Verify it for the selected header, its mating part and the board footprint. |
| I2C | a two-wire digital bus (SDA data, SCL clock); each device has an address |
| level shifter | a small board that translates 3.3 V signals to 5 V and back |
| LSB | the smallest step a DAC or ADC can take |
| net | a group of pins that are all connected together; has a name (GND, 3V3, SDA) |
| node | a set of holes joined by copper or by wires; one node carries one net |
| OL | Meter indication whose meaning depends on the selected meter, mode, range and circuit. Interpret it using the meter documentation and verified acceptance criterion. |
| pad | the copper ring around a hole (or a flat copper area for SMD) |
| pin 1 | The reference pin of a connector or IC. A square pad, dot, or notch can be a clue. Confirm pin 1 and the viewing side against the selected footprint and component documentation. |
| pigtail | a short cable with a connector on one end and bare wires on the other |
| polarised | a part that only works one way round |
| rail | a long strip of joined holes along a board edge, used for supply or ground |
| shunt | a small resistor through which the measured current flows |
| silkscreen | the white printing on a PCB |
| SMD | surface-mount device; soldered onto pads, no legs through the board |
| strip | A group of holes joined by a continuous piece of copper. The verified board geometry shows which holes share each strip. |
| strain relief | tape, a zip tie or a loop so pulling a cable does not pull a joint |
| through-hole | a part with legs that go through the board |
| tinning | coating a wire end or iron tip with a thin layer of solder |
| VIH / VIL | the lowest voltage a device reads as "1" / highest it reads as "0" |
| wick | copper braid that soaks up molten solder |
