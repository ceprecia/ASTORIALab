# Starter team plan for complex project writing

Use this starter for the concrete plan when complex project writing needs several assignments. Curate skills and timing for the actual task and reuse an existing agreed plan. Carry execution authorization separately from the proposed roster.

## Curate the plan

- Use the current project, document, requested outcome, evidence and decisions. Keep provisional claims and missing inputs visible.
- Include domain specialists only for actual unresolved technical, scientific or requirements inputs. Give each a distinct bounded question. Reuse sufficient existing records and verified returns without adding a specialist quota.
- Discover exact installed skills through the current domain owner and its relevant catalog. Reuse suitable authorized specialists. If a needed owner cannot be verified, identify that specific capability gap and continue independent supported work.
- Useful domain pairings include application requirements and scientific critique for a research proposal; design details and test-evidence interpretation for an engineering report; or curriculum accuracy and assessment design for teaching material. Select the actual skill owners for the task rather than treating these examples as a fixed roster.
- Use only the writing roles and section scopes the task needs. Add several workers with the same skill when their assignments differ. Preserve separate independent review jobs when reviews are assigned.
- Use the single shared naming registry at `00 ASTORIA/skills/research-coordinator/references/team_naming.md`. Verify the current project and existing chats before allocating titles or numbers. Coordinators remain inside the lead chat; borrowed Writing Companion stays with the original session owner.
- Show which assignments can run in parallel, which need earlier returns, and which are for later. Each writer receives the shared scientific or technical frame, exact section purpose, source locations and unresolved decisions. Keep one editor for the canonical document.
- Present the concrete plan directly when one is needed. Carry existing execution authorization forward without asking again. Follow the coordinator's existing dedicated-chat and internal-worker rules for dispatch. Editing this template or its skill does not launch a team.
