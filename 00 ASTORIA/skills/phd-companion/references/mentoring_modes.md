# Academic and career mentoring modes

Use these modes for degree progress, professional relationships, authorship and career decisions.

## Modes

Choose the mode that fits. If unclear, state the chosen mode and proceed. The output lists are prompts for useful content, not mandatory headings or an intake checklist; omit points that do not help the current request.

### Mode A: Milestone and Progress Strategy

Use when the user needs to clarify progress, thesis scope, deadlines, project priority, or what counts as enough.

Output:

1. Situation
2. Minimum defensible milestone
3. Main bottleneck
4. Scope risks
5. Recommended next step
6. Backup option
7. What to clarify with advisor or committee

### Mode B: Advisor and Mentoring Network

Use when the user needs to prepare for advisor, PI, committee, senior trainee, collaborator, or external mentor conversations.

Output:

1. Situation
2. What expectations are explicit
3. What expectations are still implicit
4. Conversation goal
5. Suggested talking points
6. Documentation to create or update
7. Who else should be on the mentoring bench

### Mode C: Sponsorship and Visibility

Use when the user needs to become more visible or competitive.

Output:

1. Target opportunity or audience
2. Evidence the user has now
3. Evidence still needed
4. Possible sponsors
5. Specific ask to make
6. Next visible action
7. Risk of waiting

### Mode D: Authorship, Credit, and Conflict

Use when authorship, order, contribution, data use, credit, responsibility, or lab conflict is unclear.

Output:

1. Situation
2. Type of academic or professional problem: communication, expectations, contribution, credit, or policy
3. Current facts
4. Missing policy or field norms
5. Safest clarification step
6. Documentation plan
7. Escalation route if clarification fails

### Mode E: Career Direction and Transition

Use when the user is weighing postdoc, faculty, industry, policy, entrepreneurship, or keeping options open.

Output:

1. Current career hypothesis
2. Best evidence for that path
3. Weakest part of the case
4. Alternative paths worth keeping alive
5. Six-month evidence target
6. One high-leverage next action
7. Decision point to revisit
